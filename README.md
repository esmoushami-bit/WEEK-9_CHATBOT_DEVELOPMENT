# Week 9: Chatbot Development Using Ollama

## 1. Project Overview
This project develops a simple AI chatbot using Python and Ollama. The chatbot answers user questions using a locally running Large Language Model (LLM).

## 2. Objectives
- To develop a chatbot using Python.
- To interact with a locally running AI model.
- To store chatbot conversations in CSV and text files.
- To analyze chatbot responses using a Jupyter Notebook.

## 3. Technologies Used
- **Programming Language:** Python
- **AI Framework:** Ollama
- **Language Model:** Llama 3.2
- **Libraries:** Pandas, Jupyter Notebook
- **IDE:** Visual Studio Code

## 5. Features
- Answers questions using the Llama 3.2 model.
- Processes sample questions from a CSV file.
- Saves conversation history and chatbot responses.
- Maintains a text log of conversations.
- Analyzes chatbot responses using Pandas.
- Exports response analysis results to a CSV file.

## 6. Installation and Setup

### Step 1: Install Ollama
Download Ollama from https://ollama.com/download.

### Step 2: Download the Model
Open the terminal and run:

```bash
ollama pull llama3.2
```

### Step 3: Install Python Libraries
Activate your virtual environment and run:

```bash
pip install -r requirements.txt
```

### Step 4: Run the Chatbot
From the main project folder, run:

```bash
python chatbot.py
```

### Step 5: Run the Jupyter Notebook
Open `notebook/Week9_Chatbot_Development.ipynb` in VS Code and run the cells to analyze the chatbot conversations.

## 7. Dataset Description
- **sample_questions.csv:** Contains sample questions for testing the chatbot.
- **chat_history.csv:** Stores conversation history.
- **responses.csv:** Stores chatbot responses.
- **chatbot_logs.txt:** Records conversations in text format.
- **response_analysis.csv:** Contains the response analysis results generated by the notebook.

*Note: Some output files are created automatically when the chatbot or notebook runs.*

## 8. Observations
- The chatbot generates answers to user questions using the selected language model.
- Conversation data can be stored and analyzed using Python.
- Response length and conversation history can be examined using Pandas.

## 9. Limitations
- Response quality depends on the selected language model.
- Ollama must be installed and running locally.
- The chatbot may sometimes generate incorrect or irrelevant answers.
- Response generation depends on available system resources.

## 10. Conclusion
This project demonstrates how to build a simple AI chatbot using Python and Ollama. It also demonstrates conversation logging, CSV data handling, and chatbot response analysis using a Jupyter Notebook.
